========================================
  Checkers Gate API — Cloudflare Worker
========================================

Зачем: чтобы значки ♙♔♕ работали у всех, у кого стоит расширение
(сервер помнит userId тех, кто установил расширение).

----------------------------------------
1. Регистрация Cloudflare (бесплатно)
----------------------------------------
https://dash.cloudflare.com/sign-up
Карта не нужна.

----------------------------------------
2. Создать Worker
----------------------------------------
1) Слева: Workers & Pages → Create → Create Worker
2) Имя, например: checkers-gate
3) Deploy (сначала пустой)
4) Edit code → удали всё → вставь код из worker.js
5) Deploy

----------------------------------------
3. Подключить базу KV
----------------------------------------
1) Workers & Pages → KV → Create a namespace
   Имя: checkers-gate-users
2) Вернись в свой Worker → Settings → Bindings → Add
   Type: KV Namespace
   Variable name: USERS   ← обязательно именно USERS
   KV namespace: checkers-gate-users
3) Save → Deploy ещё раз

----------------------------------------
4. Скопировать URL
----------------------------------------
Вид: https://checkers-gate.ТВОЙ_САБДОМЕН.workers.dev

Открой в браузере:
  https://...workers.dev/health
Должно быть: {"ok":true,"service":"checkers-gate"}

----------------------------------------
5. Вставить URL в расширение
----------------------------------------
Открой файл badge.js
Найди строку:
  const API_BASE = "https://YOUR-WORKER.workers.dev";
Замени на свой URL (без слэша в конце).

Переустанови расширение (chrome://extensions → обновить).

----------------------------------------
Проверка
----------------------------------------
POST /register — расширение само шлёт при заходе на Roblox
GET  /rank/1515075892 → {"rank":"king",...}
GET  /rank/1388899632 → {"rank":"queen",...}
GET  /rank/ЛЮБОЙ_КТО_УСТАНОВИЛ → {"rank":"pawn",...}
GET  /rank/чужой_без_расширения → {"rank":"none",...}
